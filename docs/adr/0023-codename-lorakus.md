# ADR-0023 — Nom de code LORAKUS

- **Statut** : Validé (2026-11-08)
- **Date** : 2026-11-08
- **Revue prévue** : avant toute ouverture commerciale

## Contexte

« Jarvis » est associé à une marque Marvel et très utilisé pour des assistants. Le projet a besoin d'un nom de code stable pour le dépôt, les paquets et l'app Android.

## Décision

Nom de code : **LORAKUS** (`lorakus` en minuscules dans le code : paquet Python `lorakus`, modules `lorakus_modules`, images `ghcr.io/anasknanoua/lorakus`, app Android `io.github.anasknanoua.lorakus`). Le nom affiché à l'utilisateur est une variable de configuration (`APP_DISPLAY_NAME`, défaut « Lorakus »), indépendante du nom de code.

## Alternatives rejetées

Kairo, Nestor (déjà utilisés par plusieurs assistants IA), Vigie (connotation de surveillance), Alba, Ozan, Milo.

## Conséquences

Une recherche du 2026-11-08 ne montre aucun produit nommé Lorakus. Une marque commerciale distincte pourra être choisie et déposée plus tard sans renommer le code.
