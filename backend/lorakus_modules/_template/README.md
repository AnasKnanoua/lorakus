# Gabarit de module

Ce dossier n'est jamais chargé en production : il n'a pas d'entry point. Il sert de point de départ à `make new-module` et montre les règles d'un module (tables préfixées avec `user_id`, RLS forcée, configuration validée, routes protégées par le Core). Ce fichier n'est pas copié dans le nouveau module.
